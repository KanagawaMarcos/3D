# 3D Files Repository

This repository serves as a unified collection of my public 3D files, projects, and assets. It contains various 3D models, renders, and project files from different software platforms.

## About

This is my central repository for organizing and sharing 3D content across various tools and workflows. The repository includes work from multiple 3D creation and rendering applications, making it easier to manage and share my 3D projects in one place.

## Supported Software & Formats

This repository may contain files from the following 3D software and formats:

- **Blender** - 3D modeling, animation, and rendering files (.blend)
- **Fusion 360** - CAD and parametric modeling files (.f3d, .f3z)
- **FreeCAD** - Open-source CAD files (.FCStd)
- **Unreal Engine** - Game engine projects and assets
- **Renders** - Final rendered images and animations (PNG, JPG, MP4, etc.)
- **General 3D Formats** - OBJ, FBX, STL, GLTF, and other interchange formats

## Repository Structure

The repository is organized to accommodate different types of 3D content:

- Projects may be organized by software, project type, or creation date
- Rendered outputs and final assets
- Source files for 3D models and scenes
- Related textures, materials, and resources
